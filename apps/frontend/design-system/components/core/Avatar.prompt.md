Avatar for users, providers, and data sources. Image or initials fallback, optional status dot.

```jsx
<Avatar name="Mara Voss" status="verified" />
<Avatar src="/logos/coinbase.png" name="Coinbase" square />
<Avatar name="Stork" size="lg" tint="var(--viz-3)" status="pending" />
```

Sizes `xs | sm | md | lg`. `square` for provider logos. `status` accepts `verified | pending | rejected | offline` or any CSS color.
